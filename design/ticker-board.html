The ticker board ▲

One server-rendered page that reads like a brokerage watchlist for your own counters. It uses Jinja2 and one vendored uPlot file, with no bundler and no framework. Every number on this page is generated sample data, not your real counts. The charts are live, so try the range buttons, click rows, and hover the big chart.

  • Change comes firstEvery row answers "how much did this move in the range I picked?" before it answers "what is it now?"
  • Steps, not curvesStore-on-change data holds its value until the next change. Lines step, and bars show the net change per bucket, like trading volume.
  • Stale data looks staleWhen a source stops answering, its line goes dashed after the last good poll and the row gets a chip. A flat line never pretends to be live.

Overview

GET / · one call to /api/stats/overview?range=1M per refresh

nas.local:8080/?range=1M
One range switch
1D through ALL drives every sparkline, change column, the mover ranking and the big chart. It's kept in the URL.
Index strip
Pinned headline tiles, set with dashboard.pinned in config. When nothing is pinned, the first four cumulative metrics show.
Big chart
Shows whichever tile, mover or row is selected. It has a crosshair readout, a right-hand axis with the last-value tag, and change bars underneath.
Biggest moves / latest changes
Moves ranks series by % change in the range. Latest changes is a tape of the newest recorded changes across every plugin.
Watchlist
One row per active series, grouped by plugin. Per-model series fold under a toggle so dozens of models don't bury the profile totals.
Status line
One dot per plugin from /api/plugins, using the same amber/red thresholds as /health/plugins.

Metric detail

GET /m/{metric_key}?range=3M

nas.local:8080/m/makerworld.model.1180234.downloads?range=3M
Deep link
Clicking a row's name opens this page. It's bookmarkable, and the back button returns to the overview with the same range.
Recorded changes
The raw stored samples, newest first. They show exactly what store-on-change kept instead of a smoothed story.
Open on source
Appears only when the series' attrs carry a url, like MakerWorld models and GitHub repos.

Phone

Same page, below 640 px

No separate mobile view
It's the same template and CSS. Tiles swipe sideways, and the table collapses to name, sparkline, value and change.
Tap for detail
Rows link to the metric detail page, where the chart takes the full width.
Theme
Dark by default and light on toggle. The choice is remembered per browser.

In scope

  • Overview + metric detail: two routes, both server-rendered, with charts hydrated from JSON
  • 60-second auto-refresh that updates values in place without a full reload
  • Dark and light, responsive, keyboard reachable
  • Offline-safe assets: uPlot and fonts vendored into static/, no CDN

Left out on purpose

  • Logins, users, or editing config from the browser
  • Overlaying or comparing series on one chart
  • Drag-and-drop layouts or custom dashboards
  • Alerts and milestones (Phase 8, via Home Assistant)
  • Any JS framework, bundler or npm step
